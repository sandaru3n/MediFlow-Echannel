# MediFlow — frontend

Next.js (App Router, JavaScript/JSX) app for MediFlow.

```bash
cp .env.example .env.local   # fill in Supabase keys and OTP_SECRET
npm install
npm run dev                  # http://localhost:3000
```

Database setup, environment variables, the security model and creating the first admin are documented in the [project README](../README.md).
